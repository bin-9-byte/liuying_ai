# React Project 启动指南

## 项目概述
基于 Vite + React 18 + TypeScript + Three.js 的 AI 设计网站项目，包含 Landing 首页和 Studio 工作台，支持 WebGL 粒子背景和着色器动画效果。

## . - react-project

### 快速启动

```bash
npm run dev
```

**启动后访问**：http://localhost:5173

```yaml
subProjectPath: .
command: npm run dev
cwd: .
port: 5173
previewUrl: http://localhost:5173
description: Vite + React 18 + TypeScript + Three.js AI 设计网站，包含 Landing 首页（WebGL 粒子背景 + Three.js 光球）和 Studio 工作台（三栏布局）
```
